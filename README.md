# Reformas Mallorca Palacios

Sitio web estático para Reformas Mallorca Palacios, empresa de reformas integrales y parciales en Mallorca.

## Contenido

- `index.html` — la página web completa (Hero, Servicios, Proyectos, Opiniones, Presupuesto, Contacto, chatbot de citas)
- `DESIGN.md` — sistema de diseño (colores, tipografía, espaciados)
- `screen.png` — captura de referencia del diseño original
- `server.ps1` — servidor local en PowerShell para previsualizar la web en `http://localhost:8080` durante el desarrollo (no se usa en producción)

## Despliegue

Sitio estático sin build ni dependencias: se sirve directamente `index.html`. Compatible con Vercel, Netlify, GitHub Pages o cualquier hosting estático.
